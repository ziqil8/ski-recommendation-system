# Ski Resort Recommendation System

An intelligent recommendation platform that helps users discover the most suitable ski resorts based on budget, skill level, terrain preference, and travel goals.

The system combines personalized filtering, ranking logic, and user review data to simplify destination selection and improve travel decision efficiency.

Users can search, compare, and evaluate resorts through an interactive platform with real-time recommendations and structured resort insights.

## Key Features

- Personalized recommendation engine  
- Multi-factor ranking system  
- Search & filter experience  
- User reviews and ratings  
- Full-stack web architecture  
- SQL-backed data management

## Tech Stack

Python, JavaScript, SQL, Flask, REST API
